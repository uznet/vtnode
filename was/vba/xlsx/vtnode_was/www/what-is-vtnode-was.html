INTRO

What is VTNode WAS?

VTNode WAS는 Excel을 웹 애플리케이션 서버로 연결합니다. 브라우저와 스마트폰의 요청을 Excel VBA 애플리케이션으로 전달합니다.

Browser / Phone
→
VTNode WAS
→
Excel VBA App

Excel 안에서 연결하고 실행합니다

VTNode가 네트워크와 런타임을 담당하고, Excel 사용자는 URI별 업무 화면과 로직을 자유롭게 추가합니다.

1

HTTP 요청

브라우저와 모바일 기기의 요청을 Excel에서 직접 수신하고 응답합니다.

2

WebSocket 연결

Excel과 여러 클라이언트 사이에서 실시간 메시지를 주고받습니다.

3

URI Routing

/table-order처럼 URI를 VBA 기능과 연결해 앱을 확장합니다.
