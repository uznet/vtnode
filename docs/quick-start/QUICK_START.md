# VTNode WAS for XLSX Quick Start

**English** | [한국어](./QUICK_START.ko.md)

Install the VTNode Runtime and run your first example in which Excel/VBA responds to a browser request.

> VTNode runs one channel without a license, time limit, or feature restrictions. Verify the basic workflow first, then get a free 4-channel license if you need more concurrent connections.

## Overview

```text
01 Install the VTNode Runtime
        ↓
02 Verify the installation with VTNodeCheck64
        ↓
03 Download the Excel example from GitHub
        ↓
04 Run one channel without a license
        ↓
05 Verify the browser response
        ↓
Optional: Get a free 4-channel license
```

## 1. Install the VTNode Runtime

Download the latest Windows x64 installer from the [VTNode Downloads page](https://vtnode.io/en/downloads/).

```text
VTNode-Setup-<version>-x64.exe
```

Enter your email address and accept the required terms on the download page. VTNode will email you a download link that remains available for a limited time.

The installer automatically performs the following tasks:

- Installs the VTNode Runtime
- Configures the `VTNODE_HOME` environment variable
- Creates the folders and files required by the Runtime

You do not need to configure `VTNODE_HOME` manually.

## 2. Verify the installation

The **Check the VTNode Runtime installation** option is selected by default on the final installer screen.

```text
☑ Check the VTNode Runtime installation
```

When setup finishes, `VTNodeCheck64.exe` runs automatically and checks:

- The Runtime path configured in `VTNODE_HOME`
- The installed VTNode package version
- The Runtime directory and required files
- The final installation status

Example of a successful result:

```text
VTNode Runtime Installation Check

VTNODE_HOME     : C:\Program Files\VTNode
Package Version : <installed-version>
Required Files  : OK
Status          : OK
```

If you clear the check option during setup, or want to verify the installation again later, run `VTNodeCheck64.exe` from the installation directory.

If the result shows `Status : ERROR`, review the accompanying reason and check the installation again.

## 3. Download the Excel example

Download the [VTNode WAS for XLSX example](https://github.com/uznet/vtnode/tree/main/was/xlsx) from GitHub.

Before opening the example XLSM file:

1. Extract the archive first if you downloaded one.
2. If Windows has blocked the file, open its **Properties** and unblock it.
3. Open the XLSM file in Excel.
4. Confirm that the file is from a trusted source, then enable macros.

## 4. Run without a license

Start VTNode WAS from the example XLSM. You do not need to apply for a license or enter a license code for the first run.

License-free operation includes:

- Concurrent connections: 1 channel
- Time limit: None
- Feature restrictions: None

We recommend using this mode first to verify the connection between the Runtime and Excel/VBA.

## 5. Verify the browser response

Open the address shown in Excel in a desktop or mobile browser.

```text
Browser
   → VTNode Runtime
   → Excel/VBA
   → HTTP Response
   → Browser
```

Quick Start is complete when the browser request reaches Excel/VBA and the response generated by VBA appears in the browser.

## Extend the example with AI

Attach the actual VBA module from the downloaded GitHub example and ask your AI assistant:

> Using the existing VTNode APIs and code structure, write VBA code that returns the value of `Sheet1!B2` as JSON when a `GET /status` request is received. Also explain which module and location should contain the code.

Providing the actual example module helps prevent the AI from inventing VTNode APIs that do not exist. Before running generated code, verify that it matches the APIs and structure of the example you are using.

## Troubleshooting

### Excel cannot find the Runtime

- Completely close and restart Excel if it was running during installation.
- Run `VTNodeCheck64.exe` and verify `VTNODE_HOME` and the required files.

### Macros do not run

- Confirm that Windows has not blocked the XLSM file.
- Enable macros only after confirming that the file came from a trusted source.

### The browser receives no response

- Confirm that `VTNodeCheck64.exe` reports a final status of `OK`.
- Confirm that VTNode WAS is running in Excel.
- Enter the address shown in Excel exactly as displayed.
