Quick-Start  를 2단계로 나누자 

1. VTNode Runtime 설치단계
     -VTNode Runtime 을vtnode.io 에서  다운로드하여 설치 
     -설치후 VTHello64.exe 를 실행시킨후 출력 메시지를 확인 한다.

2.실행 단계

   - Gthub 에서 VTNode WAS for XLSX 다운로드  
   - 라이센스 코드 없이  실행 하기
       라이센스 없이 곧바로 1채널 실행이 가능 
   - 무료 라이센스 코드로 실행 하기 
       vtnode.io 에서 무료 라이센스(4채널) 를 발급받은후 실행 가능
       


설치 프로그램이 VTNODE_HOME을 자동 설정하는가
    ->yes
VTHello64.exe의 정확한 성공 출력은 무엇인가
   -> 이름을 VTVersion64 로 바꾸자.
        VTNODE_HOME 환경 변수 출력
        설치된 package version 을 출력 
 
무료라이선스 1채널 실행에 기간 제한이나 기능 제한이 추가로 있는가
   --> 기간/기능 제한 없다.
