무료 라이센스 발급 방법 

1. VTNode Runtime 설치
2.  Reg Code 생성하기 
      VTMakeRegCode64 실행 후 메시지확인후 성공이면 
      {VTNode Home}/licenses/ 폴더에 vtnode_regcode.vtreg 파일이 생성된다.
3.Meta Code 생성 하기
   2단계에서 생성된 vtnode_regcode.vtreg 를 vtode.io 에서 무료라이센스 발급받기에서 안내에 따라  실핼한후 
   Meta Code 를 다운받는다.
4. License Code 생성 및 등록 
   Down 받은 Meta Code 를 VTNode Runtime 에 설치된 Device(Windows PC) 에서  아래와같이 
       VTActivateMetaCode64  <meta  code file> 
    (License Code 생성과정에서는 반드시 device(PC) 가 인터넷이 가능해야한다)
   
   처럼 실행한후 .결과를 확인한다. 
   결과가 성공적미면 {VTNOde HOME}/licenses/  폴더에 라이센스 코드가 만들어 진다. 
   이후 license-id (라이센스 파일이름) 를 vtnode_httpa_params.ini 에 아래와같이 등록 해서 사용하면 된다
   [license]
    enabled = true
    id= "license-id"
